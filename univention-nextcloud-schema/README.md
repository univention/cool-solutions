# Package: univention-nextcloud-schema

Packaged version of the schema for Nextcloud udm attributes for groups and users
Copied from the nextcloud app, original found [here](https://github.com/nextcloud/univention-app/blob/master/nextcloud.schema)
Meant to be used in conjuncion with the [Blog article](https://www.univention.com/blog-en/2021/09/integrate-nextcloud-manually-into-ucs/#The_agony_of_choice) for manual integration of Nextcloud with UCS
